# Twin Calendar

A calendar that shows this month and next month at once, marking days that have a daily note.

## Main features

- **Two months at once** — this month on top, next month below. Switch to one calendar in the settings.
- **Daily note marker** — a dot or any character/emoji (e.g. ✓ ★ 🔥) under days that have a daily note.
- **Click a day** — opens that day's daily note, or creates it from your template if it doesn't exist.
- **Navigation** — ‹ / Today / › move both calendars together.

## Installation

Manually: download `main.js`, `manifest.json` and `styles.css` from the release.
